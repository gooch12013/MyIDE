# Prompt guide: FLUX (Black Forest Labs)

Guidance drawn from Black Forest Labs' FLUX.2 prompting guide (docs.bfl.ai). Covers flux_2, flux_3_image and flux_kontext. Edit freely.

- Order matters: FLUX pays most attention to what comes first. Subject, then action, then style, then context.
- Length: 30 to 80 words suits most assets; go longer only for scenes with many elements.
- Colours: write "color #0047AB" or "in hex #1B6B6F" next to the object it applies to. For gradients give the start and end colours.
- Text: wrap it in quotes ("the word 'OPEN' in red neon"), give its placement, font style and size.
- References (up to 8 on pro, 10 on FLUX 3): say what each reference contributes to the result.
- Flux Kontext is an editor: describe the change to the reference in one or two sentences and what stays the same.
