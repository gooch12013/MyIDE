# Prompt guide: any image model (fallback)

Guidance, not rules. Used when no guide matches the chosen model. Edit this file to change how prompts are written for every model without its own guide.

- Write a short description of the scene in full sentences, not a keyword list.
- Order: subject first, then what it is doing, then style, then setting, lighting and colours, then constraints.
- Say what the asset is for (app icon, website hero, empty state) so the model picks a fitting composition.
- Give colours as hex codes tied to specific objects ("buoy body in #e7e9ec").
- Put any text that must appear in quotes, and name its style and placement. If no text is wanted, say "no text, no letters".
- Prefer positive phrasing ("an empty beach") over long lists of negatives.
- Icons and logos: one strong silhouette, flat or lightly shaded shapes, generous negative space, readable at 48 px, subject inside the central safe area.
- When iterating from a reference, say what changes and list what must stay the same.
