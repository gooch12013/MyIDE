# Prompt guide: Nano Banana (Google Gemini image models)

Guidance drawn from Google's "How to prompt Gemini 2.5 Flash Image Generation for the best results" (developers.googleblog.com). Covers nano_banana, nano_banana_pro, nano_banana_2 and later versions. Edit freely.

- Describe the scene in a narrative paragraph; full sentences beat keyword lists.
- Be specific: subject, setting, materials, textures, mood.
- State the purpose ("an app icon for a tide-logging app", "a logo for a small bakery").
- Use photographic and cinematic language for composition: wide shot, macro, 85 mm lens, low angle, soft studio light.
- Name the lighting and colour scheme explicitly; hex codes are fine.
- Text: give the exact words in quotes, the font style and where it sits. Nano Banana Pro handles text and diagrams best.
- Use positive descriptions ("an empty street") rather than negatives ("no cars").
- Editing with a reference image: say what to change and that everything else (style, lighting, perspective, framing) stays as in the reference. The model keeps the reference's aspect ratio when editing.
- Small changes per round work better than rewriting the whole prompt.
